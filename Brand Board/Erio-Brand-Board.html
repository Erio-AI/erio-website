04

Visual Language

Style Principles

Rounded Corners

Soft radii throughout. 12px small, 18px medium, 28px large. Never sharp edges.

Gracious Spacing

Generous padding and whitespace. Let elements breathe. Avoid dense clutter.

Glassmorphic Blur

Frosted translucent surfaces with backdrop blur. Subtle borders. Ambient depth.

Subtle Neon Glow

Soft cyan halos on interactive elements. Restraint over intensity.

Gradient Light

Directional teal gradients for buttons, backgrounds, and text highlights.

Smooth Motion

Premium micro-animations. Cubic-bezier easing. Slow, confident, never jittery.

Modern Tech Feel

Clean, confident, future-facing. Never clunky, dated, or overly corporate.

Premium Quality

Every detail intentional. High-end finishing. Believably real, never gimmicky.

06

Usage Notes

Do · Don't
Do
  • Use generous spacing and soft rounded corners everywhere
  • Apply glassmorphism on overlays, modals, and cards
  • Pair dark teal backgrounds with subtle cyan glow accents
  • Use gradients directionally (top-left to bottom-right)
  • Keep animations slow, smooth, and confident
  • Use Exo 2 for all body and UI copy
Don't
  • Use colors darker than #005475 or below the palette diagonal
  • Apply harsh drop shadows or sharp corners
  • Over-saturate neon glows — keep them subtle
  • Clutter layouts with dense text blocks
  • Mix display fonts other than Android Insomnia for artistic use
  • Use bouncy, fast, or playful animations
